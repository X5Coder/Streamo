English

Windows builds of Streamo are built from this open source repository: github.com/X5Coder/Streamo

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Every Windows release (.exe) is built automatically by GitHub Actions from this repository and signed by SignPath.io with a certificate issued to SignPath Foundation. Files that are not built from this repository are never signed, and every signing request requires manual approval from the project owner before release.

What signing means — and what it does not

A valid signature means the binary was built from the public source code in this repository and was not modified after build. It does not imply endorsement of any third-party content, and it does not change your responsibility for how you use the software.
